# 会员与方案演示

入口：主站侧栏「会员与方案」或 `/#membership`。

当前平台全部开放。这里用于展示未来商业模式，不连接收款渠道，不产生真实交易、发票或教师授权。没有自动续费。

## 方案口径

| 方案 | 展示口径 | 演示行为 |
| --- | --- | --- |
| 基础学习 | 免费基础课 | 基础知识课程和 3D 拆解台始终开放 |
| 个人月会员 | 29 元／月 | 模拟开通完整部件课程、AI 带教权益、考证备考题库 |
| 个人季会员 | 69 元／季 | 同上，有效期 3 个月 |
| 个人年会员 | 199 元／年 | 同上，有效期 12 个月，推荐方案 |
| 院校试点 | 3,000–10,000 元／班／年 | 仅本地记录合作意向；种子学校可申请免费试用，期限待商议 |
| 未来院校商业化 | 10,000–30,000 元／班／年 | 作为未来参考说明，不直接下单 |
| 未来私有化 | 50,000–200,000 元／校 | 部署与年度维护的组合参考，未拆价；仅本地记录合作意向 |

个人会员价格由本次演示拟定：29 元／月、69 元／季、199 元／年，年付比连续月付节省 149 元。商业计划书仅规定年费百元级，没有写这三个具体价格。AI 次数、免费试用期限仍保持待定。院校价格按正式盈利模式中的「每班／年」展示，仍需按实际范围协商。本轮没有公开原始商业计划书。

课程访问边界为演示映射：现有「基础与诊断课程」作为免费区，「车型部件课程」作为完整会员课程；商业计划书没有逐章指定免费名单。AI 仅展示会员可访问的状态，没有虚构额度或扣减真实次数。

## 如何演示

1. 在「会员与方案」开启付费访问效果。未开通时，部件课程、故障带教与考证题库会说明所需权益；上方基础课程可正常学习。
2. 选择月／季／年周期，创建个人会员模拟订单，分别尝试取消、模拟失败与重试成功。开通后可返回刚才的学习入口。
3. 刷新页面，查看当前模拟权益与订单记录。手动续费会新建订单，从当前有效期末延长所选的 1／3／12 个月；月末按目标月的最后一天处理，重复确认同一成功订单不会重复延期。
4. 提交院校或私有化的合作意向演示。表单不向服务器发送，不会创建真实班级或修改教师身份。
5. 退出付费演示即可恢复全部开放；「重置演示」仅清当前账号的演示数据，保留学习、练习和实训记录。

## 数据与边界

- 这是浏览器本地状态演示，不是正式支付鉴权或商业计费后台。更换设备、清理浏览器数据后不保证保留模拟订单。
- 使用独立的 `et_demo_commerce_v1` 存储键，按本地账号分桶；游客单独保存。该键不会进入现有按用户名后缀收集的云端学习进度。
- 购买不写入课程完成、题目答案、成绩、实训星级或账号角色；实训仍由既有 `CourseProgress` 判定先修条件。
- 订单保存所选周期与金额快照。早期没有确定价格的演示订单继续显示「历史演示价待定」，不会重新标成按新价格成交。
- 正式上线前需要另行确定价格与额度、服务器权益校验、真实订单及支付渠道；当前演示不改变现有服务器的权限机制。

验证：`node scripts/verify-demo-billing.cjs`；原有进度与实训回归检查继续适用。
