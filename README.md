# 智电汽修二班

从看懂新能源车的结构，到在虚拟场景中练习维修。面向“油转电”技师和入门学习者，把 3D 拆解、部件课程、实训游戏与 AI 故障带教连成一条学习路径。

[打开教学平台](http://47.101.135.218/) · [观看 15 秒介绍](videos/promo-15s.mp4)

## 先看整车，再走进部件

选择纯电动、插电混动、增程式或氢燃料电池车型，在三维整车中查看动力电池、电机、电控和其他部件。点击部件进入课程，把结构位置与工作原理对应起来。

## 学过的内容，在场景里练一次

课程配合随堂测验和维修实训小游戏，围绕高压下电、绝缘检测、热管理等内容练习。新手可以沿体系课学习，有经验的燃油车技师则通过进阶考核检查已有知识，再补足新能源部分。

## 带着故障现象提问

文字、故障码照片或现象视频都可以成为提问入口。AI 带教结合视觉识别、故障码知识与案例，帮助学习者理解排查思路；典型问题还可以收录为后续学习案例。

## 让练习留下记录

学习看板汇总课程、游戏成绩和错题，考证模块提供理论与看图练习。教师可以创建班级，查看班内学习进度，用同一套平台安排学习和复盘。

## 开始体验

通过[在线演示](http://47.101.135.218/)进入学生端；教师申请、班级功能和自建服务配置见使用指南。平台用于学习与模拟，不能代替实车操作规范和现场安全要求。
